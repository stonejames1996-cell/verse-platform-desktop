## What's new in 1.5.1

* **Lighter in the background.** When the app sits in the tray or is minimised, its window now goes to sleep and hands its memory back to your PC.
* **Cleans up after your game.** About 45 seconds after a match ends, the app lets go of the game pictures and data it was holding.
* **Less work while it waits for a game.** Checking which game you've opened is now much cheaper, so the app is quieter on your PC all day.
* **Screenshots no longer start a recording.** Using the Windows Snipping Tool (or ShareX, Lightshot, Greenshot) or opening Task Manager isn't treated as a game anymore.
