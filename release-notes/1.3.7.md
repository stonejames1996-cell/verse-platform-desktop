## What's new in 1.3.7

* **Shortcuts for each game.** The Finals now has its own "hide or show the box" and "move the overlays" shortcuts in its Settings section. You can use the same keys as League: they do whatever fits the game you're playing.
* **Overlay spots for each game.** Moving The Finals' box no longer moves League's, and each game has its own Reset spots button.
